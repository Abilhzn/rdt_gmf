## Blocker aktif — BELUM selesai

**Angular dev-shell (`ng serve`, port 4200) gagal compile:**

```
TS2307: Cannot find module '@angular/core' or its corresponding type
declarations. [plugin angular-compiler]
    ../../../auth/frontend/auth.module.ts:1:25
```

**Root cause**: `rdt/frontend/dev-shell/tsconfig.app.json` punya
`include: ["src/**/*.ts", "../rdt/**/*.ts", "../../../auth/frontend/**/*.ts"]`
— sengaja compile file TS dari `auth/frontend/` LANGSUNG sebagai bagian
dari build dev-shell (restrukturisasi 24 Jul motong auth keluar dari
`rdt/frontend/`). Masalahnya: `auth/frontend/` gak punya `node_modules`
sendiri (sempat ketemu folder kosong di situ, sudah dihapus), dan gak ada
`node_modules` di root `budgeting_gmf/` juga (bukan npm workspace). Jadi
waktu esbuild/TypeScript resolve `@angular/core` dari
`auth/frontend/auth.module.ts`, dia jalan ke atas cari `node_modules` dari
folder `auth/frontend/` — ketemu buntu, gak pernah nyampe ke
`rdt/frontend/dev-shell/node_modules` (itu sibling folder, bukan ancestor).

**Ini KEMUNGKINAN BESAR bug lama dari restrukturisasi 24 Jul yang belum
pernah ke-verify** (di summary sesi sebelumnya sempat dicatat "whether ng
serve actually compiled successfully is UNKNOWN") — bukan sesuatu yang
aku rusak sesi ini.

**Percobaan fix yang lagi jalan (BELUM SELESAI/BELUM TERVERIFIKASI)**:
buat Windows directory junction `auth/frontend/node_modules` →
`rdt/frontend/dev-shell/node_modules` (`mklink /J`), supaya resolusi
module ketemu duluan sebelum nyampe ke folder yang gak ada apa-apanya.
**2x percobaan lewat Git Bash `cmd.exe //c "mklink ..."` GAK KELIATAN
berhasil** (folder `node_modules` gak muncul lagi di `auth/frontend/`
setelah dijalanin) — kemungkinan masalah escaping path backslash Git
Bash → cmd.exe, bukan mklink-nya sendiri yang gagal. **Coba lagi pakai
PowerShell langsung** (`New-Item -ItemType Junction`) atau minta user
buka `cmd.exe`/PowerShell manual dan jalanin:

```
mklink /J "E:\_tadashi\project\budgeting_gmf\auth\frontend\node_modules" "E:\_tadashi\project\budgeting_gmf\rdt\frontend\dev-shell\node_modules"
```

Alternatif kalau junction tetap gak mau: pindahkan/copy `@angular/*`,
`tslib` dari `dev-shell/node_modules` ke `auth/frontend/node_modules`
langsung (duplikasi, tapi kerja), atau restrukturisasi tsconfig supaya
`auth/frontend` gak di-include langsung tapi lewat path alias yang resolve
ke dalam `dev-shell/src/` (lebih besar perubahannya, jangan buru-buru
kalau belum ada waktu buat verify).
